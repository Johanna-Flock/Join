# Join – Kanban Task Manager

## About the Project

**Join** is a web-based Kanban task management application developed as a team project. It helps users organize tasks, manage workflows, and keep track of their daily responsibilities through a clear and structured interface.

The dashboard provides an overview of tasks that need to be completed, including due dates and tasks in the To-Do stage. Users can also manage contacts through an integrated address book and organize tasks using categories.

The project was built using a design template provided as part of the course and is now completed and available online.

**Live Demo:** [join.johanna-flock.de](https://join.johanna-flock.de)

## Features

* **User Authentication** – Log in using individual user credentials.
* **Dashboard** – View tasks that need to be completed, their due dates, and tasks currently in the To-Do stage.
* **Task Management** – Organize tasks within a Kanban workflow.
* **Drag and Drop** – Move tasks between workflow stages.
* **Categories** – Organize tasks by category.
* **Address Book** – Manage and access contact information.
* **Search** – Find information more easily.
* **Responsive Design** – Use the application on different screen sizes.
* **Cloud Data Storage** – Store and manage application data using Firebase and Cloud Firestore.

## Technologies Used

* **HTML5** – Structuring the application.
* **CSS3** – Styling and responsive layouts.
* **JavaScript** – Application logic and interactive features.
* **Firebase** – Backend services and user authentication.
* **Cloud Firestore** – Cloud-based data storage.
* **Visual Studio Code** – Development environment.
* **Live Server** – Local development server.

## Getting Started

### Prerequisites

* [Visual Studio Code](https://code.visualstudio.com/)
* The **Live Server** extension for Visual Studio Code

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Open the project's main HTML file.
5. Right-click the file and select **Open with Live Server**.

The application should open in your default browser.

**Note:** If the project requires Firebase configuration, make sure the appropriate project settings are available before running it locally.
